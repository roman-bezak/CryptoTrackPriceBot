# Примеры использования CryptoTrackPriceBot 🚀

## 🎯 Основные сценарии использования

### 1. Отслеживание роста Bitcoin

**Цель**: Получить уведомление, когда Bitcoin достигнет $60,000

```
/setalert BTC 60000 above
```

**Результат**: Бот создаст оповещение и будет отслеживать цену Bitcoin. Когда цена достигнет или превысит $60,000, вы получите уведомление.

### 2. Отслеживание падения Ethereum

**Цель**: Получить уведомление, когда Ethereum упадет ниже $2,500

```
/setalert ETH 2500 below
```

**Результат**: Бот создаст оповещение и будет отслеживать цену Ethereum. Когда цена упадет до $2,500 или ниже, вы получите уведомление.

### 3. Проверка текущих цен

**Цель**: Узнать текущую цену Bitcoin

```
/price BTC
```

**Результат**: Бот покажет текущую цену Bitcoin, изменение за 24 часа и время последнего обновления.

### 4. Управление оповещениями

**Цель**: Посмотреть все ваши активные оповещения

```
/alerts
```

**Результат**: Бот покажет список всех ваших активных оповещений с ID, символами, целевыми ценами и датами создания.

### 5. Удаление оповещения

**Цель**: Удалить оповещение с ID 123

```
/deletealert 123
```

**Результат**: Бот удалит оповещение с ID 123 и подтвердит удаление.

## 🔄 Рабочий процесс

### Типичный сценарий использования

1. **Начало работы**

   ```
   /start
   ```

   Получите приветственное сообщение с описанием возможностей.

2. **Просмотр доступных криптовалют**

   ```
   /symbols
   ```

   Узнайте, какие криптовалюты поддерживаются ботом.

3. **Проверка текущих цен**

   ```
   /price BTC
   /price ETH
   ```

   Изучите текущие цены интересующих вас криптовалют.

4. **Создание оповещений**

   ```
   /setalert BTC 65000 above
   /setalert ETH 2800 below
   ```

   Создайте оповещения для отслеживания целевых цен.

5. **Проверка оповещений**

   ```
   /alerts
   ```

   Убедитесь, что оповещения созданы правильно.

6. **Получение уведомлений**
   Когда цены достигнут целевых уровней, вы автоматически получите уведомления.

7. **Управление оповещениями**
   ```
   /deletealert 1
   /stats
   ```
   Удаляйте ненужные оповещения и просматривайте статистику.

## 💡 Полезные советы

### Стратегии оповещений

1. **Консервативная стратегия**
   - Устанавливайте оповещения на значительные изменения цены (10-20%)
   - Используйте оповещения "above" для покупки и "below" для продажи

2. **Агрессивная стратегия**
   - Устанавливайте множество оповещений на разных уровнях
   - Отслеживайте как краткосрочные, так и долгосрочные цели

3. **Стратегия удержания**
   - Устанавливайте оповещения на ключевые уровни поддержки и сопротивления
   - Используйте оповещения для принятия решений о входе/выходе

### Лучшие практики

1. **Регулярно проверяйте оповещения**

   ```
   /alerts
   ```

   Убедитесь, что ваши оповещения все еще актуальны.

2. **Используйте статистику**

   ```
   /stats
   ```

   Анализируйте эффективность ваших оповещений.

3. **Не создавайте дублирующие оповещения**
   Бот автоматически предотвращает создание одинаковых оповещений.

4. **Удаляйте ненужные оповещения**
   ```
   /deletealert <ID>
   ```
   Поддерживайте список оповещений в актуальном состоянии.

## 🚨 Важные замечания

- Оповещения проверяются каждые 5 минут
- После срабатывания оповещение автоматически отключается
- Старые сработавшие оповещения удаляются через 30 дней
- Бот работает 24/7 и отправляет уведомления в любое время
- Все цены указаны в долларах США (USD)
